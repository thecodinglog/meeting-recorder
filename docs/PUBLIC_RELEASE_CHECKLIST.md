앱 아이콘은 `tools/make_icon.swift`의 도형 그리기 코드로 재생성했으며 현재 PNG와 바이트 단위로 일치했습니다. `design/icon-concepts/`의 시안과 비교 이미지는 프로젝트 작업 과정에서 AppKit의 도형·색상·텍스트로 직접 제작했습니다. 확인한 제작 코드에는 외부 이미지 파일을 가져오는 과정이 없습니다.

Gitleaks 배포 파일은 공식 체크섬과 대조했습니다. 소스와 녹음 데이터를 외부 검사 서비스에 보내지 않고 로컬에서 검사했습니다. 이 검사는 알려진 비밀 값 패턴을 찾으며 개인정보·저작권·모든 보안 결함의 부재를 보증하지 않습니다. 외부 도구·모델의 조건은 [THIRD_PARTY.md](../THIRD_PARTY.md)를 참고하세요.

## 공개·배포 시 확인

- GitHub에 올린 커밋의 Actions가 성공하는지 확인합니다. 로컬 검증과 원격 CI 검증은 별개입니다.
- 최소 지원 macOS 15와 실제 장치에서 권한, 녹음, 재생, 편집, 전화 자동 녹음의 켜짐·꺼짐을 확인합니다. 이번 자동 검증은 Apple Silicon 환경에서 수행했으며 실제 장치 검증을 대신하지 않습니다.
- 선택적 Python 패키지의 새 환경 설치와 모델 재다운로드를 검증합니다. 이번 점검에서는 수행하지 않았습니다.
- GitHub의 비공개 취약점 제보, 비밀 값 검사, push protection 설정을 확인합니다.
- 녹음 전에 참석자에게 알리고 동의를 받습니다. 전화 자동 녹음은 기본 켜짐이며 앱이 참석자에게 별도로 알리지 않습니다.
- 공개 직전 공개 대상 브랜치·태그와 추적 파일을 다시 검사합니다.

```sh
gitleaks git --redact --log-opts=--all .
git ls-files
git status --short
```

## 앱 배포

`build.sh`는 현재 Mac용 앱을 로컬 개발 인증서 또는 임시 서명으로 만듭니다. 다운로드해서 설치하는 릴리스를 제공하려면 Developer ID 서명·공증, 배포 아키텍처, 깨끗한 Mac에서의 설치와 권한 검증을 별도로 준비합니다. GitHub Actions는 앱을 자동 배포하지 않습니다.
